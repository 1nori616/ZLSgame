# 9 天冲刺方案（11/3 – 11/8）

> 目标：**8 号交一个能完整玩通一关的版本**，不是"功能很多但玩不了"。
> 原则：能用现有代码改的，绝不新写；能砍的，今天砍掉。

## 一、今天必须拍死的三个决定

### 1. 技能释放方式：**按键即时施放**（沿用现有 demo）

保留 `Q / E / F` 三个键，**不做"先锁定再选技能"**。

理由：
- 现有代码已经跑通，零成本
- 目标锁定已经自动做了（圆形搜索 + 朝向优先），不需要额外 UI
- 6 天做瞄准 UI + 技能轮盘 = 至少 2 天，且大概率做不完

### 2. 资源：**香蕉充能，粑粑减重，特殊香蕉翻转**

| 动作 | 效果 | 数值 |
|---|---|---|
| 吃香蕉 | 重力充能 +1（上限 3） | 每根 +1 |
| 拉粑粑 | 消耗 1 充能，进入"轻身" 4 秒（跳跃更高、下落更慢） | 消耗 1 |
| 吃特殊香蕉 | 房间重力翻转 10 秒 | 每关 1~2 根 |

**逻辑闭环**：吃香蕉→变重（能压人）→拉粑粑→变轻（能跳上去拿香蕉）。资源有进有出，不是无限。

### 3. 翻转重力的范围：**整个房间，玩家和敌人一起翻**

不是"只翻敌人"，也不是"只翻自己"。

- 玩家落到天花板、脚朝上、跳跃方向反向
- 敌人同样翻转
- **镜头不旋转**（2D 里转镜头会晕）

实现成本：约 0.5 天（Motor 增加 `gravitySign`，Sprite 用 `flipY`）。

## 二、关卡对接：策划直接在 Unity 里摆（不要用 Excel）

**结论：策划用 Unity Tilemap 摆关卡，程序提供"关卡工具箱"。**

理由：Excel / Tiled 导出都要写导入器（1~2 天），而 Tilemap 是 Unity 自带的，**零对接成本**。

### 程序今天要做的准备（约 3 小时）

新建 `Level_01` 场景，放好：

1. `Grid` + `Tilemap`（命名 `Floor`），给 Tilemap 刷一个地砖占位
2. `Tilemap`（命名 `Hazard`，放尖刺/陷阱）
3. 一套**预制体**（策划只管拖）：

| 预制体 | 用途 | 命名 |
|---|---|---|
| `P_Banana` | 普通香蕉（+充能） | 复制摆放 |
| `P_SpecialBanana` | 特殊香蕉（翻转） | 每关 1~2 个 |
| `P_Enemy` | 敌人 | 复制摆放 |
| `P_Spawn` | 玩家出生点 | 每关 1 个 |
| `P_Goal` | 终点 | 每关 1 个 |
| `P_Platform_Moving` | 移动平台（可选） | P2 |

### 策划要学的三个操作（30 分钟）

1. 选 `Tilemap` → 用 `Tile Palette` 画笔刷地面
2. 从 `Project` 拖预制体进场景，摆位置
3. `Ctrl + S` 保存 → 提交

**规则**：`Level_01.unity` 只有策划能改，程序不改。避免场景冲突。
