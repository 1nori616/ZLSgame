# 重律崩坏 / Gravity Collapse

> 在失控的空间站里，把重力当武器——锁定、失重、甩出去，让敌人砸敌人。

一款 **2D 横版动作平台游戏**，核心机制是重力操控与物理投掷。
9 天完成的可玩原型（MVP）。

---

## 快速开始

1. 下载 Release 中的压缩包并解压（不要只单独拷贝 exe）
2. 双击 `重律崩坏.exe` 运行
3. 封面点击「开始游戏」或按空格

**运行环境**：Windows 64 位

---

## 操作

| 按键 | 功能 |
|---|---|
| `A` / `D` | 左右移动 |
| `空格` | 跳跃 |
| `Shift` | 冲刺（带白色颗粒尾迹） |
| `鼠标左键` | 锁定目标（点击自己 = 自锁） |
| `Q` | 反重力（使目标失重上浮） |
| `E` | 超重（朝**鼠标方向**甩出） |
| 长按 `F` 0.7 秒 | 失重场（全场重力归零） |
| `R` | 死亡后重新开始 |

---

## 核心玩法

不直接攻击——**改变重力，让世界替你攻击**。

- **连环炮**：把敌人甩向另一个敌人，敌人之间会互相碰撞、撞飞
- **箱子炸弹**：箱子是一次性武器，撞到敌人炸开，范围伤害 + 击退
- **掉坑击杀**：敌人掉出地图即死亡，可以把敌人甩进深坑
- **自锁机动**：锁定自己可上浮越过高台，或砸地换位移（落地会自伤）
- **失重场**：全场漂浮，用来脱离包围

### 资源

- 充能 8 格，每 1.2 秒恢复 1 格
- 普通施放消耗 1 格；**自锁消耗 4 格 + 6 秒冷却**
- 充能不足时 HUD 充能格会闪红提示

### 打击反馈

顿帧 + 震屏 + 白闪 + 命中火花 + 音效 + 连击计数；
击杀时进入「慢动作 → 定格 → 炸开」，多次击杀共享同一次慢动作。

## 项目结构与工具

```
Assets/
  Art/            美术素材（角色、敌人、地砖、背景、动画）
  Levels/         关卡文本（Level_01.txt / Level_02.txt / 提示文本 / 关卡顺序）
  Prefabs/        玩家、敌人、箱子、终点预制体
  Resources/      运行时加载资源（音效、音乐、封面）
  Scenes/Levels/  生成的关卡场景
  Scripts/        游戏逻辑
    Player/       移动、重力施放、生命
    Enemy/        敌人 AI
    Gravity/      重力系统与撞击伤害
    Effects/      击杀、顿帧、震屏、连击、尾迹
    UI/           HUD、血条
    Audio/        音效与背景音乐
    Editor/       关卡生成器（Tools → 关卡 → 从文本生成关卡）
Docs/             关卡搭建手册
```

**关卡工作流**：策划用表格绘制地图 → 脚本转换为 `Assets/Levels/Level_XX.txt` → Unity 菜单 `Tools → 关卡 → 从文本生成关卡` 自动生成场景（地砖、平台、背景、舱门、开场演出、终点）。
